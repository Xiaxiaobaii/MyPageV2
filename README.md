这是我在大概24年初开始写的网页，网页第二代（第一代是python+flask,因为过于简陋加落后还有当时不懂得记录往昔所以现在找不到了），前端框架为Vue3，后端框架为golang + fasthttp。

要问为什么语言里没有golang，当然是因为后端没有开源了。

前端在后期某些页面加入了大量的AI，因为预料到想重写了所以就不太有所谓了

现在在github给这个项目立个碑，在数年后的今天第二代被淘汰并有第三代接管了

第三代：Rust + Ntex + sailfish + Alpine.js, 当然这种把自家妹妹（前端源代码）放在网上展示的感觉非常不好受，所以后期可能想办法转vite基础，至于为什么选用Alpine.js，一是因为比较轻量简单，二是因为CSR对SEO的效果不太好，三是因为编译器模板引擎的原因如果拉一大堆哈希文件shit太难处理了，如果有好办法的大佬可以发一个issue非常感谢
